not a normalized palette or type system. The source inventory contains raw
color/background/border/fill/stroke declarations and typography declarations
such as family, size, weight, line-height and letter-spacing. The earlier full
graph recorded 34,985 style observations and 809 divergence candidates; these
are review inputs, not 809 confirmed conflicts.

Component/resource taxonomy is also deliberately non-normative: fragmentation
candidates remain `NOT_MERGED / unresolved`. No candidate contract has been
promoted to accepted design-system authority.
