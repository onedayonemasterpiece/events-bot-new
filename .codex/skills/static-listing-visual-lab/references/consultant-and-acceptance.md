# Consultant and acceptance gates

## Independent formation prompt contract

Give agy/Gemini Pro:

- product jobs and explicit 20–30-card KPI;
- fresh production media statistics and definitions;
- a stratified local real-image manifest/contact sheet;
- existing accepted/rejected media lessons;
- ranking-order and MVP constraints;
- an isolated writable artifact directory.

Ask it to create renderable HTML/SVG and desktop/mobile screenshots plus rationale. Do not reveal Codex's preferred winner before formation.

## Synthesis scorecard

Score each concept 0–3 and attach screenshot evidence:

1. new visitor understands breadth and next action quickly;
2. returning user can scan 20–30 ranked cards without fatigue;
3. images retain real selling power;
4. rank order remains exact and legible;
5. OCR/document text is not destroyed or duplicated;
6. outer rhythm and alignment are harmonious across media states;
7. mixed galleries select semantically correct media;
8. low-res/no-image states remain intentional;
9. desktop and mobile both work without a hidden alternate product;
10. required metadata exists today, or fallback is explicit;
11. implementation is MVP-sized;
12. no misleading personalization/explanation claim.

Document disagreement. “Consensus” means the same recommended family and constraints survive both independent formation and later validation; it does not require identical styling.

## Fresh validation prompt contract

Start a new consultant conversation. Provide final screenshots at native viewport, media corpus/contact sheet, matrix, and scorecard. Ask the validator to:

- inspect pixels, not only markup;
- name crop, contrast, hierarchy, density, alignment, and repeated-pattern failures;
- verify no ranked item was reordered/dropped;
- identify which overlay examples are conceptual-only;
- return `FAIL`, `CONDITIONAL`, or `PASS`, with blocking fixes.

## Browser QA

At minimum capture 1440×900 and 390×844, plus one intermediate width when layout mode changes. Verify no horizontal overflow, stable reserved media space, keyboard-visible real anchors/actions, readable overlay contrast if permitted, and the complete ordered item-id sequence.

## Telegram publication receipt

Record chat/topic id, message ids, timestamp, filenames, and a read-back excerpt. Publish the visual board before or alongside the concise conclusion so the thread is not prose-only.
