Демонстратор
для Windows

Скачайте тестовый комплект, распакуйте его и запустите один файл. Node, Python и Chrome устанавливать вручную не нужно.

  1. Нажмите «Извлечь всё» для скачанного ZIP.
  2. Дважды нажмите START-DEMONSTRATOR.cmd.
  3. Дождитесь полноэкранного окна презентации.
  4. На телефоне откройте пульт и нажмите «Запустить „Завтра“».

Первый запуск скачивает зафиксированные Node-зависимости и Playwright-managed browser. Права администратора не требуются.
