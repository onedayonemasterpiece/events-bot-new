# Legacy URL-scoped парсер спецпроектов Дом искусств

## Обзор

Парсер извлекает события только с явно переданной страницы спецпроекта старого
сайта **Дом искусств** (домискусств.рф / xn--b1admiilxbaki.xn--p1ai).

Он **не является полной афишей** переименованного Калининградского театра
эстрады. Текущий полный билетный каталог подключён отдельно как `/parse
estrada`; каноника:
`docs/features/source-parsing/sources/estrada/README.md`.

## Использование

### Через бот

1. **Кнопка в меню `/vk`**: нажать кнопку "🏛 Дом искусств"
2. **Отправить ссылку** на спецпроект (например `https://домискусств.рф/skazka`)
3. Система запустит Kaggle kernel для парсинга и добавит события

### Через VK Review

При обнаружении ссылки на `домискусств.рф/...` в посте VK появится кнопка "🏛 Извлечь из Дом искусств".

## Поддерживаемые URL

```
https://xn--b1admiilxbaki.xn--p1ai/skazka
https://домискусств.рф/aladdin
https://xn--b1admiilxbaki.xn--p1ai/любой-проект
```

Автоматически пропускаются служебные страницы: `/posters`, `/news1`, `/contacts` и др.

## Формат данных

Каждая дата+время = отдельное событие:

| Поле | Источник |
|------|----------|
| `title` | Заголовок страницы |
| `date_raw` | "3 ЯНВАРЯ 14:00" |
| `parsed_date` | "2026-01-03" |
| `parsed_time` | "14:00" |
| `location` | "Дом искусств" |
| `url` | Ссылка на покупку билета |
| `ticket_status` | available/sold_out/unknown |
| `age_restriction` | "6+" |

Возраст извлекается только из standalone/явно подписанной event-page
маркировки допустимого enum. Первый произвольный `N+` во всём HTML не
используется: при нескольких значениях parser оставляет поле пустым и передаёт
контекст в semantic Smart Update.

## Технические детали

**Файлы:**
- `source_parsing/dom_iskusstv.py` — основной модуль
- `kaggle/ParseDomIskusstv/` — Kaggle notebook
- `tests/test_dom_iskusstv.py` — unit-тесты (19 тестов)
- `scripts/debug/debug_dom_iskusstv.py` — локальный debug-скрипт

**Kaggle Kernel:**
- Использует Playwright для SPA
- Парсит все карточки событий с датами
- Проверяет доступность билетов по каждой ссылке

## Ограничения

- Требует Kaggle credentials (`KAGGLE_USERNAME`, `KAGGLE_KEY`)
- Время выполнения Kaggle: 3-15 минут
- Фотографии извлекаются из основного контента страницы
