# Gemini Prompts and JSON Schemas v0.1

**Purpose:** define Gemini semantic/review loop for the Contour SVG Generator. Gemini should act as semantic analyst, editor and aesthetic judge, not as the exact-coordinate SVG generator.

---

## 1. General API notes

Use the project shared Google AI gateway. Feature code must call
`google_ai.client.GoogleAIClient` through `contour_svg.llm_gateway`; it must not
instantiate the provider SDK client directly.

```bash
pip install -q -U google-genai
```

API key:

```bash
export GEMINI_API_KEY="..."
```

Python skeleton:

```python
from contour_svg.llm_gateway import image_part, run_gateway_json_call

text = run_gateway_json_call(
    model="gemini-2.5-flash-lite",
    prompt=[
        {"text": "Analyze this image..."},
        image_part("debug/input_normalized.png"),
    ],
    generation_config={
        response_mime_type="application/json",
        response_schema=MY_SCHEMA,
        temperature=0.1,
    },
    default_env_var_name="GOOGLE_API_KEY",
    max_output_tokens=1600,
)
```

Model names change over time. Keep model name configurable:

```yaml
gemini:
  model: gemini-2.5-flash-lite
  api_key_env: GOOGLE_API_KEY
candidate_search:
  allow_gemini_line_review: true
```

## 2. Prompting rules

1. Always give the source photo and relevant debug overlays.
2. Ask for structured JSON only.
3. Use stable IDs generated by Python: `G_roof_03`, `candidate_07`, etc.
4. Ask Gemini to make decisions about meaning, not coordinates.
5. Put strict definitions of actions: keep, drop, merge_with, simplify, extend_across_occluder.
6. Ask for uncertainty and veto reasons.

## 3. Primary object selection prompt

### System/developer instruction

```text
You are a visual analyst for a vector line-art generator. Your task is to identify the primary object to draw and the objects that must not leak into the final SVG. The current priority domain is architecture. Prefer the main building/facade unless the user hint says otherwise. Return only valid JSON matching the schema.
```

### User prompt

```text
Analyze the input image for a two-color transparent SVG contour generator.

User hint: {primary_object_hint}
Priority domain: architecture first, but the system should remain generalizable.

Return:
1. The primary object that should be drawn.
2. The visible architectural features that make it recognizable.
3. Occluders that hide the primary object.
4. Background/noise objects that must not be drawn.
5. Whether conservative reconstruction through occlusion is appropriate.

Important:
- Do not choose trees, fence, sky, pavement or wires as primary object unless the user explicitly requests that.
- Distinguish attached balcony railing from foreground fence.
- If architecture is partially hidden, mark hidden zones as occluded/unknown, not as background.
```

### Schema: PrimaryObjectReport

```json
{
  "type": "object",
  "properties": {
    "primary_object": {
      "type": "object",
      "properties": {
        "label": {"type": "string"},
        "description": {"type": "string"},
        "priority_reason": {"type": "string"},
        "confidence": {"type": "number"},
        "approx_bbox_description": {"type": "string"}
      },
      "required": ["label", "description", "priority_reason", "confidence"]
    },
    "recognizable_features": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "feature": {"type": "string"},
          "importance": {"type": "string", "enum": ["primary", "secondary", "optional"]},
          "visible": {"type": "boolean"},
          "occluded": {"type": "boolean"},
          "reason": {"type": "string"}
        },
        "required": ["feature", "importance", "visible", "occluded", "reason"]
      }
    },
    "occluders": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "label": {"type": "string"},
          "severity": {"type": "string", "enum": ["low", "medium", "high"]},
          "location_description": {"type": "string"},
          "should_draw": {"type": "boolean"}
        },
        "required": ["label", "severity", "location_description", "should_draw"]
      }
    },
    "do_not_draw": {"type": "array", "items": {"type": "string"}},
    "completion_advice": {
      "type": "object",
      "properties": {
        "allow_conservative_completion": {"type": "boolean"},
        "allowed_completion_types": {"type": "array", "items": {"type": "string"}},
        "forbidden_completion_types": {"type": "array", "items": {"type": "string"}},
        "risk_note": {"type": "string"}
      },
      "required": ["allow_conservative_completion", "allowed_completion_types", "forbidden_completion_types", "risk_note"]
    }
  },
  "required": ["primary_object", "recognizable_features", "occluders", "do_not_draw", "completion_advice"]
}
```

## 4. Occluder and mask critique prompt

Inputs:

- original photo;
- mask visualization with colors;
- legend.

Prompt:

```text
Review the segmentation masks for a vector line-art generator.

Legend:
- white/blue: primary object visible
- red: occluders
- black/transparent: background
- yellow: unknown object continuation region

Find mask problems that would cause parasitic SVG lines or lost recognizable architecture.
Return JSON only.
```

Schema fields:

```json
{
  "mask_quality_score": 0,
  "critical_errors": [
    {
      "type": "tree_in_object_mask | fence_in_object_mask | building_missing | sky_in_object_mask | overmasking | undermasking | other",
      "location_description": "string",
      "severity": "low | medium | high",
      "repair_suggestion": "string"
    }
  ],
  "safe_to_continue": true
}
```

## 5. Line-group pruning prompt

Inputs:

- original photo;
- object/occluder mask overlay;
- candidate line group overlay with IDs;
- optional current SVG preview.

Prompt:

```text
You are editing line groups for a clean architectural postcard-style SVG.

The final SVG should contain only meaningful contour lines of the primary object. It must not contain lines from trees, foliage, foreground fence, sky, pavement, wires, shadows or random texture.

For each visible group ID in the overlay, choose one action:
- keep: important and clean;
- drop: noise, occluder, texture, duplicate, background;
- merge_with: duplicate or nearly duplicate of another group;
- simplify: useful but too detailed/jagged;
- extend_across_occluder: continue only if it is a confirmed architecture line hidden by occluder;
- lower_priority: keep only in detailed variants.

Return only JSON. Do not invent new group IDs.
```

Schema: LineGroupCritique

```json
{
  "type": "object",
  "properties": {
    "overall_assessment": {"type": "string"},
    "noise_risk_score": {"type": "number"},
    "recognizability_score": {"type": "number"},
    "group_actions": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "group_id": {"type": "string"},
          "action": {
            "type": "string",
            "enum": ["keep", "drop", "merge_with", "simplify", "extend_across_occluder", "lower_priority"]
          },
          "target_group_id": {"type": "string"},
          "semantic_label": {"type": "string"},
          "reason": {"type": "string"},
          "confidence": {"type": "number"}
        },
        "required": ["group_id", "action", "semantic_label", "reason", "confidence"]
      }
    },
    "missing_important_features": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "feature": {"type": "string"},
          "importance": {"type": "string", "enum": ["primary", "secondary", "optional"]},
          "suggested_search": {"type": "string"}
        },
        "required": ["feature", "importance", "suggested_search"]
      }
    }
  },
  "required": ["overall_assessment", "noise_risk_score", "recognizability_score", "group_actions"]
}
```

## 6. Candidate postcard ranking prompt

Inputs:

- original photo;
- contact sheet with candidates labeled `candidate_01` ... `candidate_12`;
- optional thumbnails 128 px to check readability;
- style target reference if allowed.

Prompt:

```text
Rank these SVG contour candidates as postcard-style line art.

Criteria:
1. Beautiful and likely appealing to viewers.
2. Recognizable primary object.
3. Clean silhouette and strong composition.
4. Minimal parasite lines from trees, fence, sky, pavement or texture.
5. Not too technical, not too noisy, not too empty.
6. Conservative reconstruction only; penalize hallucinated architecture.
7. Works as a small thumbnail.

Return the top 3 and explain the decision. Use strict JSON.
```

Schema: CandidateRanking

```json
{
  "type": "object",
  "properties": {
    "final_candidate_id": {"type": "string"},
    "top_alternatives": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "candidate_id": {"type": "string"},
          "rank": {"type": "integer"},
          "postcard_score": {"type": "number"},
          "recognizability_score": {"type": "number"},
          "cleanliness_score": {"type": "number"},
          "composition_score": {"type": "number"},
          "coarse_to_fine_present": {"type": "boolean"},
          "parasite_foliage_detected": {"type": "boolean"},
          "embedded_raster_detected": {"type": "boolean"},
          "hallucination_risk": {"type": "number"},
          "reason": {"type": "string"}
        },
        "required": ["candidate_id", "rank", "postcard_score", "recognizability_score", "cleanliness_score", "composition_score", "coarse_to_fine_present", "parasite_foliage_detected", "embedded_raster_detected", "hallucination_risk", "reason"]
      }
    },
    "rejected_candidates": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "candidate_id": {"type": "string"},
          "main_problem": {"type": "string"},
          "severity": {"type": "string", "enum": ["low", "medium", "high"]}
        },
        "required": ["candidate_id", "main_problem", "severity"]
      }
    },
    "global_repair_suggestions": {"type": "array", "items": {"type": "string"}}
  },
  "required": ["final_candidate_id", "top_alternatives", "rejected_candidates", "global_repair_suggestions"]
}
```

## 7. Pairwise tournament prompt

Use when candidates are similar.

```text
Compare candidate_A and candidate_B for a postcard-style SVG line drawing.
Choose exactly one winner unless both are unusable.
Penalize parasite lines and hallucinated architecture more heavily than minor loss of detail.
Return JSON only.
```

Schema:

```json
{
  "winner": "candidate_A | candidate_B | neither",
  "confidence": 0.0,
  "reasons_for_winner": ["string"],
  "loser_main_problem": "string",
  "repair_suggestion_for_loser": "string"
}
```

## 8. Repair plan prompt

After ranking, ask Gemini for actionable changes to the selected candidate.

```text
The selected candidate is good but may need final cleanup. Provide a repair plan that a Python SVG editor can execute. Use only these operations:
- remove_group
- lower_group_priority
- merge_groups
- simplify_group
- shorten_group
- extend_group_across_occluder
- emphasize_group
- adjust_crop

Do not invent coordinates. Refer only to existing group IDs and candidate IDs.
```

Schema:

```json
{
  "candidate_id": "string",
  "repair_actions": [
    {
      "operation": "remove_group | lower_group_priority | merge_groups | simplify_group | shorten_group | extend_group_across_occluder | emphasize_group | adjust_crop",
      "group_ids": ["string"],
      "target_group_id": "string",
      "priority": "low | medium | high",
      "reason": "string"
    }
  ],
  "expected_improvement": "string",
  "risk_note": "string"
}
```

## 9. Gemini failure handling

If Gemini returns invalid JSON:

```text
- retry with same schema and lower temperature;
- reduce number of candidates/groups;
- split tasks: first identify noisy groups, then rank candidates;
- if the shared gateway or structured response contract remains unavailable, fail the run before final export.
```

If Gemini over-penalizes detail:

```text
- include style target reference;
- specify family: minimal/balanced/detailed;
- ask for top 3 not only top 1.
```

If Gemini hallucinates group IDs:

```text
- include allowed_group_ids array in prompt;
- validate output; ignore unknown IDs;
- ask for correction with list of invalid IDs.
```

## 10. Contact sheet generation requirements

For candidate ranking:

```text
- white/off-white lines on dark neutral background for preview only;
- large candidate labels outside drawing area;
- same scale/canvas for all candidates;
- include optional 128 px thumbnail row;
- avoid visual bias from different background colors.
```

Recommended layout:

```text
3 columns × 4 rows for 12 candidates
or
4 columns × 2 rows for 8 candidates
```

For line group critique:

```text
- overlay candidate groups in random distinguishable colors;
- label IDs near group center;
- keep original photo faintly visible;
- include mask boundaries.
```
