# Автономный направляющий prototype

Прототип показывает только визуальную механику слоёв и трёх tile-state. Он не подключается к Supabase и не является второй production landing page.

```bash
python3 -m http.server 8080
```

Открыть `http://127.0.0.1:8080/docs/features/static-site-pages/prelaunch-handoff/prototype/`.
