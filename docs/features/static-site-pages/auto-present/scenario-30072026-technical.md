# Технический сценарий показа 30 июля 2026

Статус: `working_product_scenario`.

Исходные авторские требования неизменно хранятся в
[`scenario-30072026-base.md`](scenario-30072026-base.md). Этот файл — рабочее
техническое дополнение: здесь фиксируются подготовленные сцены, контент,
runtime-контракт и медиа. Он может уточняться без переписывания авторского
источника.

## Среда показа

- один Windows agent запускает один browser, один BrowserContext и одно
  fullscreen-окно;
- Run выбирает следующую явную сцену в уже открытом окне;
- Stop останавливает текущую сцену, Reset возвращает начальный экран, но не
  закрывает окно;
- только подтверждённая команда «Закрыть презентацию» завершает browser,
  agent и launcher;
- длительность всей презентационной сессии не ограничивается 30 секундами:
  будущий master-сценарий может идти около часа, оставаясь прерываемым через
  Stop/Shutdown;
- текущая версия не вводит универсальный DSL, редактор или очередь. Сцены
  остаются небольшими явными контрактами.

## Визуальный язык

- одна короткая мысль занимает весь экран;
- заголовок крупный, контрастный и читается из зала;
- служебные статусы, названия селекторов и инструкция agent-а не являются
  частью видимой композиции;
- изображение входит через мягкие `transform + opacity`, без скачка layout;
- motion учитывает `prefers-reduced-motion`;
- демонстрация сайта, текст, изображение, QR и будущая статистика являются
  равноправными типами сцен внутри одного stage.

## Реализованный аутро-кадр

**Scene ID:** `outro-qr`.

**Основная мысль:** «Как вам?»

**Поддерживающая строка:** короткое приглашение оценить мероприятие.

**Поведение:**

1. stage остаётся в существующем fullscreen-окне;
2. mobile-site композиция мягко уступает место аутро;
3. крупный QR появляется с мягким приближением;
4. кадр остаётся на экране после `completed`, пока ведущий не запустит другую
   сцену, Stop/Reset или Shutdown.

## Следующие сцены из авторского источника

Это не текущая реализация, а короткий подготовленный backlog:

1. интро-цикл за 50 минут: короткие печатающиеся фразы, случайный порядок с
   сохранением логики и знак «Знание»;
2. кинетическое знакомство с логотипом «Анонсы» через controlled stretch буквы
   «о»;
3. три пользовательские задачи события: найти, поделиться, добавить в
   календарь;
4. тезисы о фокус-группе и NPS;
5. сцена будущих функций с медальоном Татьяны Удовенко и появлением лайка;
6. лекционные текстовые/графические/статистические сцены.

Каждую следующую сцену добавляем небольшим явным контрактом и сразу
проверяем на той же непрерывной presentation session.
