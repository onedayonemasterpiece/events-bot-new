# Консолидированные требования из Telegram (сообщения 803–850, 29.07.2026)

Эта секция добавлена как traceability-реестр. Авторский сценарий выше не
переписывается; новое замечание меняет только указанную сцену и явно
переоткрывает её согласование.

## Требования к текущей итерации

1. **Стабильный пульт** (`840`, видео `845`): status/detail не должны прыгать
   при polling и смене текста; под них резервируется постоянная геометрия.
2. **Лекция управляется вручную** (`843`): семь лекционных экранов — семь
   отдельных сценариев и кнопок. Экран остаётся видимым, пока говорит спикер;
   автоматическая колода запрещена.
3. **Sticky-таймер** (`844`): сверху пульта всегда видно прошедшее время
   презентации. Для intro задаётся время начала и показывается countdown;
   в самом intro периодически появляется «Начнём через N минут».
4. **Разные композиции лекции** (`846`): горизонтальные изображения
   показываются целиком, смысл/подпись размещаются ниже; допустима отдельная
   подпись изображения. Не использовать один split-шаблон для всех кадров.
5. **Знак «Знание» без плашки** (`847`): светлый знак на тёмном фоне, тёмный
   на светлом.
6. **Контраст и ритм тем** (`848`, `849`): чередовать светлые/тёмные сцены;
   рядом с тёмным демонстрируемым сайтом использовать светлую оболочку.
7. **Место для мысли** (`850`): телефон можно сдвигать в сторону ради крупного
   тезиса. Desktop live-показ двухфазный: сначала отдельный смысловой экран,
   затем сайт во весь экран.
8. **Focus-preview**: новые live-сцены показывают версию
   `preview-20260729-focus-simple-r15-a5cc0256`, а сцена фокус-группы — точный
   invitation URL с `#invite=focus-group-2026-announcements`.
9. **Hero Talk**: intro раскрывает фразу смысловыми фрагментами с cursor у
   активного фрагмента, а не печатает по одной букве; две строки и сильная
   типографика сохраняются.
10. **Быстрые итерации**: принятые сцены замораживаются. В очередной итерации
    тестируются только новые и явно переоткрытые части; полный прогон — один
    раз перед финальным handoff.

## Уже принято и заморожено

- автоматический Windows launcher, общий versioned cache и отсутствие Enter в
  happy path (`813–815`, `819`, `831`);
- один browser/context/page/window; следующий Run, Stop и Reset не закрывают
  окно, Shutdown терминален (`819`, `827`, `831`);
- исправления GetStdHandle, UTF-8 и AbortSignal listeners (`814`, `815`);
- снятый 30-секундный rail timeout (`820`, `827`);
- mobile tap/swipe без mouse cursor, принятые сценарии rail-like, artifact и
  QR-outro — не переделывать без нового адресного замечания.
