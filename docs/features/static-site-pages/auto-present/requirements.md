# Исходные требования к автопрезентатору

> Статус: входной материал от владельца продукта. Канонические решения, MVP-граница и acceptance находятся в [README.md](README.md). Формулировки ниже сохранены для traceability и внешнего review; это не самостоятельный implementation plan.


Цель: автоматически презентовывать интерфейс статического сайта с функциями в десктоп виде и в мобильном виде

Инструменты

1. Страница для мобильного с кнопками сценария и обратным счётчиком времени презентации
2. Страница демонстрации (с которой идёт показ), точнее приложение демонтсрации
3. Сервер через который может идти обмен полезной информации (текущий девсервер)

Взаимодействие через интернет, не через локальную сеть

Проработка агентом:
[ранний Playwright PoC-промпт](playwright_autopresenter_prompt.md)

Показ должен идти по сценариям, сценарии инициируются нажатием на кнопку, сценарий может быть прерван досрочно.

Сценарии прописываются в файлах (пока их пропишет агент на основе требований)

Попробовать проверить можно на https://kenigevents.ru/_review/pp1wRctXBd6boYU1EcnBrod3z8MmKpD7SGEufK1t-xw/zavtra/ пока этой версии

Показ мобильного сопровождается показом где у нас идёт тап кругляшком (показываем на экране картинку телефона и вписываем в него интерфейс)

Показ десктопа сопровождается показом достаточно крупного указателя, которы движется естественно

В обоих случаях применяется human-like движения, плавные, но естественные, скроллы, движения мыши или тапы.

Альтернативный вариант, если не сработает в итоге презентатор на windows то сделать запись экрана playwrite с такими наложениями пойнтеров

Для начала сделай простейший MVP, который пролистает на мобильном страницу "Завтра", выберет какое-то событие, покрутит rail события вправо потом обратно влево, прокрутится вниз и выберет субботу и там пару действий сделает.

Должны быть режимы и до показа самого сайта, например:
- Написание простых фраз (typing) в формате как в hero-talk с курсором
- Показ QR-кода или иных картинок
- Показ стистической инфографики с анимацией появления их и использования сильно типографики (+ ease-in-out и хорошая дорогая кинематика)
и это всё может чередоваться, входить в общий сценарий.
