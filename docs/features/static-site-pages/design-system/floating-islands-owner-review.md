# Floating Islands — текущая исполняемая итерация

2026-09-05, PR #638, ветка `work/floating-islands-owner-preview-20260905`.

## Последнее решение владельца

Нижний desktop-вариант с широкой панелью, тяжёлой рамкой и подписями сбоку **отклонён**. Его CSS удалён. Сохранена прежняя нижняя навигация на обоих размерах. Дальнейшее направление — **один цельный остров с более маковской стилистикой**, НЕ отдельные острова-иконки. Новая skin сейчас не объявлена выбранной или реализованной. Четыре назначения и их доступность остаются.

Брендовое меню «Полюбить Калининград Анонсы» не меняется по состояниям соседних островов, не сжимается и не переставляется. На точной подборке Free канонический медальон заменяет дублирующее floating-название; H1 и дополнительный смысл других подборок сохраняются. Компактный выбор городов раскрывает исходные checkbox controls в прямоугольнике.

## Исполнение и границы

Прежний diagnostic `ccde8553…`/run33964945528 относится к **отклонённому** desktop оформлению и не подтверждает нынешнюю итерацию. Новый browser harness сравнивает не только ссылки, но и прежние размеры, координаты, paint и icon sizes нижней навигации. Повторные проверки возвращают `DIAGNOSTIC_PASS_NOT_ACCEPTANCE` только после actual run.

Остаются открыты: согласование с продвинувшимся executable trunk, единый верхний ряд без изменения бренда, registry/generated impact, постоянный scenario route, actual-corpus Kaggle preview/native P. Их нельзя объявить пройденными по старым screenshots. Read-only CI используется для существующих focused builds и чтения exact public source, не заменяет Kaggle publisher и не запускает агента.

Текущий draft не публикуется в production; experiment включён только на `/preview-islands-*`, baseline `?islands=off`. Карточки, ранжирование, transport/Auth/telemetry/foundations/STATUS не меняются этой итерацией. Установленные my-data-hub/browser/Penpot не предоставили callable methods при проверке; публичный preview не выдаётся за созданный.
