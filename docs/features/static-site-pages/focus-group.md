Мотивация: 2 билета в театр на любые спектакли активному участнику

Мотивация сработает случайно выбрав из пула тех кто выполнит условия:
- найти 80% артефактов
- давать обратную связь как минимум NPS
- плюсом будет обратная связь скриншотами и текстом в специальных блоках

Ограничения:
- авторизованы через имейл или яндекс

Механика:
- NPS по каждому типу страницы
- Возможность дать обратную связь текстом и скриншотом по странице (что-то не так, неправильная ифнормация о событии, неудобно, что-то не срабатывает)
- Артефакты-пасхалки разбросанные по всему интерфейсу так, чтобы их нужно было найти
