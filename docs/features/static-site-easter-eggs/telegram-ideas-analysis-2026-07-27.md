## Нейминг: найденная эволюция

В сообщениях `483–519` объект называется «пасхалкой». В `586–590` появляется
«артефакт». Явного owner-сообщения «название утверждено» нет.

Продуктовое решение:

- **пасхалка** — объяснение способа обнаружения;
- **артефакт** — публичное имя найденной единицы;
- **коллекция** — ограниченный набор артефактов;
- **реестр** — полный редакционный каталог всех идей;
- внутренний domain prefix — `collectible_*`, чтобы не спутать объект с build
  artifacts.

Публичная формула после owner clarification: **«В неожиданных и иногда тайных
местах интерфейса спрятаны пасхалки. Найденные пасхалки становятся артефактами
Калининградской области в вашей коллекции»**. Слово «городские» исключено:
механика относится к интерфейсу, а предметы представляют весь регион.

## Нормализация сырого банка

Из сообщений `485–511`, `583–584`, `592`, `596–597`, `605`, `668` извлечены и
дедуплицированы `139` candidate concepts. Среди них:

- море и транспорт;
- природа и животные;
- архитектура и фортификация;
- культурные персонажи и люди;
- технологии и индустриальные объекты;
- гастрономия;
- курортная и бытовая история;
- современная культура и спорт.

Полный список не копируется в этот документ. Единственный редактируемый
source-of-truth:
[`site/src/data/artifactRegistry.json`](../../../site/src/data/artifactRegistry.json).
Он рендерит страницу `/artefakty/` и public-safe JSON `/data/artifacts.json`.

## Конфликты идей и disposition

| Idea | Decision |
|---|---|
| «Собрать все» | **Изменено:** розыгрыш не требует 100%; применяется опубликованный threshold, чтобы один сложный/недоступный объект не блокировал участие. |
| Недельная ротация объектов | **Отклонено для первой коллекции:** все элементы фиксированного набора доступны одновременно в одном окне. |
| Соцпост сильно повышает шанс | **Отклонено:** share доброволен и не меняет odds; иначе это скрытая цена участия и источник gaming. |
| Передача артефакта по QR | **Вне первого prize release:** переносимое владение конфликтует с «сам нашёл» и anti-abuse. Возможен отдельный non-prize social experiment. |
| Keyboard-only секрет | **Только optional bonus:** обязательный для порога объект имеет эквивалентный keyboard/screen-reader path. |
| Случайное новое место | **Отклонено:** assignment bundle фиксируется до find/expiry. |
| Полный публичный placement registry | **Отклонено:** public page показывает определения, но не active/future hidden coordinates; полный placement inventory остаётся admin-only. |
| Client-side vector search | **Отложено:** обычные категории и поиск по статическому реестру достаточны для MVP. |

## Границы достоверности

Telegram-сообщение фиксирует идею, а не факт о регионе и не право на изображение.
Каждая запись остаётся `candidate|needs_clarification|collection_draft`, пока не
пройдены:

1. идентификация конкретного объекта;
2. source-grounded факт;
3. visual/IP permission;
4. freshness и партнёрское подтверждение;
5. safety/accessibility review;
6. owner acceptance exact registry version.
