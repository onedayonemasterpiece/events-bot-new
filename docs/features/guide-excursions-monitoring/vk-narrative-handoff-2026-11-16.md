# Codex · три публикации ежедневного экскурсионного дайджеста ВК

Выпустите подряд три рассказа с картинками в [пустой паблик владельца](https://vk.ru/club243343951). Берите реальные экскурсии из базы действующего Events Bot на RunCoveer. Используйте версию кода из этой ветки в рабочем окружении бота. Штатная команда `scripts/guide_visual_digest.py publish` вызывает тот же `publish_visual_digest_to_vk`, что и планировщик. Он сам вызывает writer, рендерит карточки, загружает их и публикует запись. Код Fable вошёл исходным коммитом `0ff094800`.

| Публикация | Подборка | Получатель единственной отметки |
| --- | --- | --- |
| 1 | Реальный выпуск №349, если он доступен | `858363572` |
| 2 | Сегодняшняя подборка или последний отличный от первого реальный выпуск | `1134828279` |
| 3 | Другой недавний выпуск с иным составом. При наличии возьмите выездную экскурсию или двух гидов | `858363572` |

Выберите три разных существующих ID визуальных выпусков с экскурсиями, чтобы различались и тексты, и карточки. Ниже команда для первого. Для остальных подставьте выбранный `--issue-id` и получателя из таблицы. Сегодняшнюю свежую подборку можно собрать этой же командой без `--issue-id`. В тестовом паблике команду можно повторить с тем же выпуском для сравнения моделей на одном материале. Каждый намеренный запуск создаёт новый пост. Для сравнения используйте доступные модели через обычный `GUIDE_DIGEST_WRITER_MODEL` только в окружении конкретного запуска. Укажите фактическую модель для каждого поста. Различия набора и модели учитывайте при сравнении.

```bash
python scripts/guide_visual_digest.py --db /data/db.sqlite publish \
  --issue-id 349 --group-id 243343951 --publish-date 0 --test-mention 858363572
```

Общий флаг реальных упоминаний оставьте выключенным. В пробном посте имена гидов сохранены, а первое подходящее имя ведёт на указанный тестовый профиль. Если подходящего имени нет, в конце появится одна подписанная отметка. Издание, отправленное в пустой паблик, не расходует экскурсии из сегодняшнего отбора. Если после отправки пропала связь, проверьте последние записи на стене перед повтором. После согласования владельцем сегодняшний дайджест выходит тем же кодом, с обычным адресом сообщества и без параметра тестового получателя. Включение реальных отметок согласуется отдельно.

Верните три ссылки ВК рядом и несколько конкретных наблюдений о тексте и картинках. Проверьте на телефоне первый экран, раскрытие записи, форму и набор номера. У №349 сверьте запись на 21 ноября и роль ведущей фермы с первым источником. В ручном образце «большинство из нас проходит не глядя» не опирается на анонс, а смысл названия «Рассвет над Балтикой» подан как установленный факт. Если в сгенерированном рассказе есть похожая проблема, процитируйте фразу и укажите, что было в данных. Для владельца и Fable положите ссылки и выводы в `vk-narrative-runs-2026-11.md` рядом с этим файлом.
