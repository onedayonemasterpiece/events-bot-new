# Исследования пользовательских историй, Jobs и измеримости продукта

Этот каталог хранит исходные результаты двух внешних глубоких исследований. Они используются как доказательная и методологическая база, но **не заменяют принятые продуктовые требования**: конкретные решения должны отдельно фиксироваться в канонических feature-, analytics- и release-документах.

Канонический внутренний синтез и правила применения находятся в
[`docs/product-model/README.md`](../../product-model/README.md).

## Правило применения

```text
внешнее исследование
→ внутренняя методология
→ явное продуктовое решение
→ канонический контракт требования
→ реализация, тесты и production evidence
```

При конфликте исследовательского вывода с более поздним явным решением владельца продукта действует решение владельца в затронутой части. Исследования не следует переписывать задним числом: изменения и принятые выводы фиксируются в отдельных канонических документах со ссылкой на источник.
