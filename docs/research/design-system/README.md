# Исследования дизайн-системы бренда и сайта

Этот каталог хранит два независимых исходных результата глубокого исследования архитектуры дизайн-системы для зонтичного бренда «Полюбить Калининград» и продукта «Полюбить Калининград Анонсы».

Исследования сохранены **отдельно и без сведения в один текст**. Они являются доказательной и методологической базой, но не заменяют канонические требования и фактические решения проекта. Нормативная документация действующей дизайн-системы находится в [`docs/features/static-site-pages/design-system/README.md`](../../features/static-site-pages/design-system/README.md).

## Существенное расхождение

Оба отчёта согласны с общей слоистой моделью, ролью семантических токенов, доступности и автоматического контроля соответствия. Их главное архитектурное противоречие — **репозиторная модель и source of truth**:

- исследование 01: один репозиторий сайта до появления второго реального потребителя; Git-код и релизный manifest являются окончательным контрактом, Figma — связанной средой проектирования;
- исследование 02: отдельный monorepo уже сейчас; Figma Variables управляют визуальными значениями и экспортируются в код.

Это противоречие намеренно не исправлено внутри исходных материалов. Его следует разрешить отдельным синтезом и явным ADR с учётом уже существующей реализации проекта, стоимости миграции и планов появления второго продукта.

## Правило применения

```text
внешнее исследование
→ сравнительный синтез
→ явное решение владельца продукта / ADR
→ канонический контракт дизайн-системы
→ реализация, тесты и production evidence
```

Исходные отчёты не переписываются задним числом. Принятые решения, поправки к фактам и расхождения с текущим кодом фиксируются в канонической документации и ADR со ссылкой на соответствующий отчёт.
