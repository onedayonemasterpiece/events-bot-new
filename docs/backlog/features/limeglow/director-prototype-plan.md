# Limeglow Director Prototype Plan

Рабочий документ Codex для `debug-05` -> `debug-07`. Канонические требования остаются в `requirements.md`; этот файл фиксирует, как текущий прототип проверяет эти требования и референсный ролик.

## Проверка по requirements.md

Прототип должен проверять не один вручную придуманный показ, а минимальную функцию электронного режиссера:

- формат `720x1280`, локальная отладка ключевых кадров до полного ролика;
- общий темный 2.5D-холст, а не slideshow;
- два независимых экскурсионных узла дайджеста, без логики "первая/вторая прогулка";
- у каждого узла есть хук, гид, дата/время и собственные коллаж-объекты;
- в каждом экскурсионном узле должен быть хотя бы один overlap-beat, где хук/ФИО гида/дата/визуальный объект пересекаются в одном читаемом фокусе;
- хуки берутся по принципам `engagementcards.md`: короткий вопрос/интрига, крупная читаемая типографика, без эмодзи;
- маршруты камеры меняют направление: push-in, боковой проезд, вертикальный переход, pull-back;
- все видимые слои подчинены одной камере: zoom влияет на все, depth дает только parallax, scale-bias и микроотставание;
- спикеры крупные, узнаваемые, с разными обработками; approved-прием `echo/clone` закреплен в прототипе;
- крупная фоновая типографика "ЭКСКУРСИИ", "ГИДЫ", "МАРШРУТЫ" работает как архитектура сцены;
- финал собирает общий lockup с CTA "выбери прогулку в дайджесте".

## Проверка по референсу

Из референса переносится:

- кинетический editorial collage / broadcast opener;
- большой холст и камера, летящая между смысловыми островами;
- темная база, монохромные люди, яркие плашки, сильная обрезанная типографика;
- разный rhythm внутри одного ролика: объектный крупный план, hero portrait, triptych/echo, финальный отъезд;
- микро-UI и геометрия как локальные акценты, без постоянных полосок/сетки;
- финальный lockup, где несколько людей и объектов видны вместе.

Не переносится:

- интерфейс YouTube;
- бренд/логотипы исходного ролика;
- горизонтальная композиция один-в-один;
- перегруз мелким текстом.

## Product Story For Debug-05

Ролик продает не "маршрут", а выбор в дайджесте экскурсий. Три магнита внимания:

1. Хук: короткий вопрос из логики engagementcards.
2. Гид: крупное фото без фона, с премиальной монохромной обработкой и echo-копиями.
3. Образ экскурсии: коллажный объект, связанный именно с этим экскурсионным узлом.

Для продуктовой ясности эти магниты не должны всё время жить на разных экранах: режиссёр обязан делать пересечение "гид покажет это, тогда-то" внутри каждого узла.

Отладочные узлы:

- `Амалиенау`: один кирпичный фасад как визуальный объект, без skyline/труб как чужого суррогата; хук "Что скрывает немецкая вилла на тихой улице?"
- `Кёнигсбергский трамвай`: один трамвайный объект как hero-коллаж; мороженое допустимо только как короткий foreground-wipe в переходе, не как третий продуктовый образ; хук "Куда ведут рельсы старого Кёнигсберга?"

## Director Variant

`debug-07` использует фиксированный seed, чтобы кадры были воспроизводимы, но структура оформлена как вариант, который позднее можно перепроектировать:

- `route_variant`: `blender-board-with-depth-planes`;
- `intro_style`: общий дайджестный тизер с крупной типографикой и фрагментами спикеров;
- `scene_A_archetype`: `hero-object-cluster`;
- `transition_A_to_B`: `camera-drift + foreground-object-wipe`;
- `scene_B_archetype`: `object-first + guide-echo`;
- `cta_style`: `pullback-lockup`.

`debug-07` заменяет Pillow-preview на Blender 2.5D-сцену:

- есть реальная перспективная камера и Z/depth-планы: far typography, mid plates/cards, hero portraits/objects, foreground tags/CTA/props;
- zoom/проезд камеры влияет на все слои сразу, а различие глубины дает честный parallax;
- echo-копии спикеров живут на смещенных depth-плоскостях и анимируются появлением/settle, а не стоят как статичная декорация;
- у каждого экскурсионного узла есть окно видимости: старые объекты не протекают в финальный CTA;
- люди не висят в воздухе: портреты уходят за нижний край кадра, крупные объекты могут выходить за края при push-in;
- в кадре нет служебных слов вроде "крючки" или "foreground-проп";
- для headless Blender-preview нужен шрифт с кириллицей (`fonts-dejavu-core` в Docker), иначе дефолтный Blender-font ломает русские буквы;
- текущий быстрый preview рендерится в `12 fps`, `96` кадров, `720x1280`, через Workbench/OpenGL под Xvfb.

## Keyframe Contract

Ключевые кадры должны показывать интервалы от начала до конца:

- `KF-00`: общий тизер, еще без "все и сразу";
- `KF-01`: вход в первый хук;
- `KF-02`: крупный гид первого узла с echo;
- `KF-03`: архитектурные объекты первого узла;
- `KF-04`: переход через крупный foreground-проп без служебной надписи;
- `KF-05`: вход во второй хук;
- `KF-06`: крупный гид второго узла с другой обработкой echo;
- `KF-07`: трамвайный объект как единственный tram hero;
- `KF-08`: промежуточный широкий отъезд;
- `KF-09`: финальный CTA-lockup.
