**3. Одна рекомендуемая desktop-система**

Для разрешений 1920, 1440 и 1366 px внедрить единый геометрический стандарт:
- **Max-width / внешние отступы:** Контейнер центрирован, max-width 1440px. Внешние отступы (padding-x): 120px для 1920, 80px для 1440, 60px для 1366.
- **Высота hero:** min-height 40vh, max-height 50vh (не более 450px абсолютной высоты).
- **Text column width:** 8 колонок из 12 (или ~60–65% ширины контейнера).
- **H1:**
  - Preferred size: 72px (min 56px для 1366, max 80px для 1920).
  - Line-height: `1.05`–`1.1` (tight, для плотной акциденции).
  - Целевое число строк: 2–3.
- **Small media:**
  - Width: 320–360px, Aspect ratio: 3:4 или 4:5 (вертикальный журнальный портрет).
  - Позиция: right-aligned в пределах контейнера, оптически выровнено по центру текстового блока.
  - Crop: Плотный close-up.
  - Оформление: **Никаких теней и белых рамок.** Минимальный radius 4–8px. Медиа должно быть частью плоской композиции.
- **Место декоративной O:** В правой трети контейнера, за текстом и кнопками (z-index: -1).
- **Header badge:** Фиксированная высота 48px, внутренние отступы 0 24px. Минимальная безопасная зона для lockup «Анонсы» — 160px. Никакого набранного текста, только SVG-ассет.
- **CTA и Next:** Gap между ними — 32px. Primary CTA должен быть визуально тяжелее (если ссылка — то с жирным underline и крупной стрелкой). Public Next — строго вторичный (ghost-стиль с тонкой рамкой или просто muted-текст без фона).

**4. Motion/kinematics (5–8 параметров)**

Не делать из медиа слайд-шоу. Движение должно быть быстрым и кинетичным.
1. **Durations:** Базовая длительность 600ms (общий вход), 400ms (внутренние элементы).
2. **Easing:** `cubic-bezier(0.2, 0.8, 0.2, 1)` (snappy out, медленное торможение).
3. **Порядок появления:** H1 (fade + translate Y 20px) -> Primary CTA -> Small Media / Декоративная O (fade + scale 0.95 to 1.0).
4. **Small media:** Появляется на месте (opacity), никаких вылетов из-за края экрана.
5. **Уход (нажатие Next):** Элементы не растворяются всей группой. Сначала исчезает медиа (200ms), затем типографика уходит в blur/fade.
6. **Cursor:** Убрать стандартный pointer с медиа, если оно не кликабельно; добавить микро-параллакс при движении мыши (shift X/Y на 2-4px).
7. **Reduced-motion:** Полное отключение translate и scale, оставить только 300ms cross-fade (opacity).
