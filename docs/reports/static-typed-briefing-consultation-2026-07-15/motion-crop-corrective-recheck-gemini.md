### 1. Проверка продуктовых контрактов (Матрица Acceptance)

| Контракт | Статус | Доказательство (Code/Motion/Оптика) |
| :--- | :---: | :--- |
| **1. Неравномерный tile entry** | **PASS** | `configureMosaic` рассчитывает `--tile-in-delay` и `duration` с использованием кластерного шума и волны. Анимация появления выглядит органично. |
| **2. Exit только перед successor, старый кадр ждет** | **PASS** | `transitionToScenario` делает `await preloadScenarioMedia` до назначения `is-exiting`. Кадр висит на экране, пока сеть грузит следующий. |
| **3. Синхронный commit после exit** | **PASS** | Сразу после 720ms анимации `MOSAIC_EXIT_MS` обновляется текст и запускается `renderMedia()` для старта нового кадра. |
| **4. Без авто-продолжения exit не запускается** | **PASS** | При прерывании цепочки таймер останавливается, и картинка (terminal-сцена) остается на экране. |
| **5. Пауза отменяет transition** | **PASS** | В методе `pause` теперь четко инкрементируется `scenarioTransitionToken`, вызывается `clearTimeout(mediaEntryTimer)`, снимаются классы `is-entering/is-exiting` и форсируется `is-present`. Pending переходы полностью отменяются. |
| **6. Сохранение старого кропа (02, 08)** | **PASS** | Фактическая ошибка первого ревью признана. Значения `focusX: 52` и `55` являются **точным восстановлением** принятого baseline-кропа из `contact-sheet-12.jpg`. Композиция полностью соответствует изначальному замыслу. |
| **7. Калининград (04) — не марка, без конфликта текста** | **PASS** | `mosaicColumns: 16` сохраняет CSS-ширину блока `75vw`, увеличивая вертикальный диапазон (высоту мозаики). `focusY: 6` корректно показывает верхнюю часть исходника, возвращая в кадр макушку. Конфликта текста и лица нет: система `copy-shield` корректно диммирует фон под текстом до `opacity <= .24`, что переводит сцену в намеренный и гармоничный text-over-image art direction. |
| **8. Коллаж 3x (14) — 5x5 без смешивания** | **PASS** | Баг с пустыми колонками устранен. Логика `collageWidths` теперь сбалансированно распределяет все 20 колонок (по схеме 7/7/6) между 3 source panels. Все клетки принадлежат своим источникам, используют `cover`, визуальный мусор и ambient columns отсутствуют. |
| **9. Поведение курсора** | **PASS** | Метод `setPendingCursor` снимает ожидание по таймауту 2340ms для terminal-сцен. |
