## Вектор и две потерянные рекомендации

Поиск работает в `pgvector`, индекс HNSW, метрика — косинусная близость. Карточки кодирует `gemini-embedding-2` в векторы из 768 чисел. В эксперименте менялось представление события. Рабочий v2 описывает заголовок и содержание, U использует заголовок, короткое описание и принятое редакторское описание `Event.search_digest`. Каждый вектор нормировали, складывали и нормировали сумму. В предлагаемом рецепте нужна одна строка для `related_v1`. U существует в архиве эксперимента. Рабочий `search_v3` кодирует другой текст.

Все расчёты ниже используют одни и те же 690 событий. «Попадание» означает, что один из подтверждённых сеансов желательной программы вошёл в первые 20 кандидатов до Gemma. Использован сборщик из PR #1027, включая упорядочивание программ и граф связей. Ответ RPC воспроизведён по сохранённым векторам с ограничением в 60 соседей и штатными правилами при равенстве. Это воспроизведение на снимке, а не повтор 690 запросов к рабочему индексу. В независимом наборе 67 положительных пар у 15 исходных карточек. Исходный набор из 17 включает два дополнительных контрольных примера.

| Представление (вес v2 : U) | Исходные 17 | Новые 67 | Потери относительно v2 в этом же сборщике |
|---|---:|---:|---|
| Рабочий v2 | 12 | 55 | Исходный уровень |
| Только U | 14 | 54 | Потери есть уже по числу попаданий на новых парах |
| 1 : 1 | 15 | 57 | 10580 → 11021 и 10398 |
| 2 : 1 | 15 | 57 | 10580 → 11021, с 15-го места на 21-е |
| 3 : 1 | 15 | 57 | 10612 → 11079, с 20-го на 22-е |
| 4 : 1 | 15 | 57 | 10612 → 11079, с 20-го на 21-е |

На одних и тех же 84 парах при равной смеси в штатном сборщике семь желательных программ вошли, две вышли. Обе потери приходятся на «Кентервильское привидение» (10580). «Покажите мультики» (11021) перемещается с 15-го места на 24-е, «Звук падения» (10398) с 14-го на 22-е. Получить хорошее среднее здесь можно даже при потере двух релевантных фильмов у одного зрителя. Коэффициенты 2, 3 и 4 проверены на тех же данных после первого результата. Это проверка чувствительности вывода, а не независимая валидация коэффициента.

Fable использовал другой знаменатель для ранга. Его скрипт может схлопнуть всё множество из 690 событий по подтверждённым связям и тексту в кавычках, затем выбрать первые 20. Точный повтор в этом режиме дал 69 → 75 попаданий из 84, **восемь вошли, две вышли**. В отчёте указаны десять вошедших. Если в его же скрипте оставить только подтверждённые связи, выходит 68 → 73. При штатном отборе из таблицы выше получается 67 → 72. Данные по всем 84 парам включены в приложение.

**Проверка потерь у 10580.** Передали все 20 исходных кандидатов v2 в Gemma. «Звук падения» получил 0,40 и явный отказ, «Покажите мультики из своей коллекции» — 0,35 и отказ. Посты обоих фильмов видны в VK. В результате штатный отбор v2 дал только «Фильм, фильм, фильм» (10915). У смеси этот кинопоказ остался первым кандидатом. На первой пачке смешанного варианта сработал общий лимитер, поэтому итог для этой карточки остаётся непроверенным. [Прошедший кинопоказ](https://vk.com/wall-231920894_13692) · [Оценки и отбор](../fable-related-search-20261116/execution-evidence.json)

**Решение по векторам.** Готовить к отдельному испытанию равную смесь. У неё прослежен реальный выигрыш до публичных ссылок на фильмы. Для более сложного выбора весов дополнительной пользы на независимом материале не показано. Показ по исходным и смешанным векторам полностью сопоставлен для одной карточки. Это ограничивает вывод о качестве на всём каталоге. Ветка кандидата ведётся отдельно и требует сверки нового состава каталога до переключения. [Код кандидата](https://github.com/onedayonemasterpiece/events-bot-new/tree/review/related-vector-content-mix-20261116)

**Сколько стоит выпуск.** На 16:12 UTC в рабочем каталоге 699 событий. Совпали оба архивных входа у 686 из 690 прежних карточек. Изменились 10421, 10442, 10752 и 10940, добавилось девять новых. При переиспользовании валидных архивных пар у оставшихся 13 событий нужно получить недостающие компоненты. Стоимость штатной полной сборки без архива — до 1398 вызовов только для related; текущий лимит одного прохода 500. На каждой новой карточке два related-вызова вместо одного. Запрос читателя по-прежнему сравнивает один вектор, замера времени ответа после выпуска ещё нет. Время формирования и технические издержки миграции растут.

**Порядок переключения вектора.** Агенту релиза сначала получить и проверить новый полный набор вне работающего индекса, сохранить исходные векторы, документы и метаданные для отката, повторить незавершённую проверку для 10580 на действующей политике и убедиться, что 10915 доходит до списка VK. Только затем переключать целиком согласованную версию документов и векторов, проверить полный receipt и обновить общий Kaggle-граф. Старая RPC выбирает строки по kind/model/dim; номер рецепта в метаданных сам по себе не изолирует частичный пересчёт. Простая запись порциями в единственную рабочую колонку смешала бы две версии. Откат требует восстановления сохранённых данных вместе с кодом. Подробности фактически реализованного кандидата и границы выпуска указаны в его PR.

## Что считать одной постановкой

У «Красного фонаря» (11071) семь подтверждённых повторов были приняты Gemma как самостоятельные программы. Это доказанный ложный показ. Штатный наблюдатель связей получил исходные сведения о двух сеансах 11071 и 11072. Первый ответ модели не удалось разобрать как JSON, затем истёк общий лимит 90 секунд. Ответ отдельной проверки тех же 14 участников с принудительной схемой завершился HTTP 503. Есть источник, подтверждающий сеансы. Согласованная запись связей после обычного импорта остаётся предметом проверки. Работа над отличием гастролей той же постановки от самостоятельной интерпретации уже идёт в PR #1023. [Исходный анонс](https://vk.com/wall-43887582_14877) · [PR #1023](https://github.com/onedayonemasterpiece/events-bot-new/pull/1023)

У 36 групп из отчёта совпал нормализованный фрагмент названия. Это 135 карточек, требующих проверки. В «Янтарь-холле» Светлогорска под названием «Щелкунчик» идут балет театра Вячеслава Гордеева 19 декабря (7236) и новогодняя сказка с юными артистами Калининграда 5 января (10346, 10436). Автоматическое объединение скрыло бы самостоятельную постановку. Совпадение названия и площадки здесь тоже даёт ошибку. Действующее правило VK отдаёт свободное место другой дате уже отобранной самостоятельной программы, если разных программ меньше пяти. Оно требует сначала правильно определить самостоятельность относительно исходной карточки. Для таблицы штатного отбора объедини исходную разметку Fable с его же `replay.py`. Извлекаются только два словаря разметки, остальные вычисления выполняет закреплённый в репозитории экспортёр.

```bash
python - "$workdir/snapshot" <<'PY'
import ast
import contextlib
import importlib.util
import io
import json
import sys
import tempfile
from pathlib import Path

snapshot = Path(sys.argv[1])
directory = Path("docs/reports/fable-related-search-20261116").resolve()
spec = importlib.util.spec_from_file_location("review_replay", directory / "replay.py")
replay = importlib.util.module_from_spec(spec)
spec.loader.exec_module(replay)
tree = ast.parse((directory / "fable_analysis.py").read_text())
sets = {n.targets[0].id: ast.literal_eval(n.value) for n in tree.body
        if isinstance(n, ast.Assign) and isinstance(n.targets[0], ast.Name)
        and n.targets[0].id in {"ORIG", "FABLE"}}
def cases(pairs):
    return [{"anchor": a, "preferred": peers} for a, peers in pairs.items()]
rows = [json.loads(line) for line in (snapshot / "vectors.jsonl").read_text().splitlines()]
with tempfile.TemporaryDirectory() as tmp:
    labels = Path(tmp) / "labels.json"
    labels.write_text(json.dumps({"quality_expectations": {
        "cases": cases(sets["ORIG"]), "fresh_holdouts": cases(sets["FABLE"])}}))
    replay.EVIDENCE = str(labels)
    with contextlib.redirect_stdout(io.StringIO()) as buf:
        replay.graph_comparison(snapshot, rows)
    results = json.loads(buf.getvalue())
for name in ("pr", "experimental", "equal_mix"):
    print(name, *[results[name][group]["programme_at_20"]
                  for group in ("cases", "fresh_holdouts")])
```
