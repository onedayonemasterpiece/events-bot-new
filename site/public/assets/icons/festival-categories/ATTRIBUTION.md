# Festival category icons

The festival calendar uses one visually coherent `24 × 24`, two-pixel,
round-cap icon family from SVG Repo's
[Lucide Line Icons](https://www.svgrepo.com/collection/lucide-line-icons/).
All selected files are listed by SVG Repo under the **CC0 License**.

the shared line art can inherit the category-chip colour without rewriting the
source.
