# Event question CTA icons

Both durable assets are exact copies from the shared SVG Repo library and retain
its metadata sidecars.

- `question-bubble-390478.svg`: library id
  `svgrepo-390478-bubble-chat-comment-conversation-message-talk`, SVG Repo
  <https://www.svgrepo.com/svg/390478/bubble-chat-comment-conversation-message-talk>,
  **CC0 License**. Selected after visual comparison with the thinner chat-bubble
  option because its open outline remains legible at the CTA's 22 px size.
- `vk-repost-348786.svg`: library id `svgrepo-348786-repost`, SVG Repo
  <https://www.svgrepo.com/svg/348786/repost>, **CC0 License**. Selected from the
  social/share contact sheet because the compact, bold repost silhouette remains
  readable at 18 px and communicates that the question opens under a VK post.

The files are not redrawn or geometrically adapted. CSS only scales them and
places each black source mark on a contrasting light tile.
